# Reopen Albert Bridge

Campaign website for residents and businesses of Battersea and Chelsea affected by the Albert Bridge closure.

Live site: https://reopenalbertbridge.co.uk

Static single-page site. To edit content, change `index.html`; images live in `assets/`.
The campaign email and open-letter link are set in one place — the `CAMPAIGN CONFIG` block near the bottom of `index.html`.
